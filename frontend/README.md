# Johen Donate React Frontend

Frontend React + Vite hasil pemisahan dari aplikasi Next.js. Tampilan, halaman, dashboard, donasi, payout, admin, dan overlay tetap mengikuti alur aplikasi lama.

## Menjalankan

1. Salin `.env.example` menjadi `.env`.
2. Isi `VITE_MIDTRANS_CLIENT_KEY`.
3. Jalankan `npm install` lalu `npm run dev`.

Backend default berjalan di `http://localhost:8001` dan frontend di `http://localhost:3000`.
